# 仅做 L2/H∞：创新性与近似论文核查

核查日期：2026-09-26。对象为 `texdocs` 的力矩级对偶四元数控制器及《两阶段多Gamma力矩级鲁棒推导》中第 1--4 节和附录 A--C 的 **L2** 结论。本文不把持续扰动最终有界性、ISS 或 L∞ 结论算入候选论文贡献。这里的“查重”是公开文献中的**技术重合核查**，不是全文文字相似度检测；未取得付费全文的工作不能据摘要断言其没有某个定理。

## 核查结论

1. **已有技术高度接近，但目前未在所查公开材料中确认“机械臂力矩级 DQ + 非线性位姿/twist 四输出 L2 证书 + 四 Gamma 显式反演”这一完整命题。** 这只说明检索到的材料未直接覆盖完整组合，不是首创证明。
2. **单凭四个 Gamma 和 Schur 补，理论创新性偏弱。** DQ 运动学 H∞ 的多 Gamma 设计已有 [1,2]；DQ 机械臂加速度/力矩控制已有 [3--5]；机械臂动力学的 L2/H∞ 已有 [6]。当前新结果更准确地称作：在特定 DQ 误差动力学上构造局部、四输出的显式**充分**增益设计。
3. **投稿潜力取决于是否证明并验证“组合后得到以前没有的可操作性能”。** 只列出 `Kp(gamma), Kd(gamma)`，且性能输入仍是等效加速度扰动 `d`，容易被评为已有 CTC、DQ 误差和标准耗散工具的组合。若把关节力矩 L2 输入、留域能量预算、可实现约束和证书保守性量化为同一个可复现实验/设计流程，应用型控制论文才有较强说服力。

## 当前四 Gamma 证明的真实增量与保守性

现有推导对理想等效误差模型给出

\[
\dot e_z=A(\tilde x)e_\xi,\qquad
\dot e_\xi=-K_de_\xi-A(\tilde x)^\top K_pe_z+d,
\]

并在正四元数分支、`J` 满行秩、固定工作域内证明

\[
\dot W_s+\gamma_{s,z}^{-2}\|e_{z,s}\|^2
        +\gamma_{s,\xi}^{-2}\|e_{\xi,s}\|^2
\le\|d_s\|^2,\qquad s\in\{\omega,v\}.
\]

其具体可检查之处是利用四元数标量部 `1-eta` 及 `T×omega` 的反对称谱结构，得到不含 `dot A` 的局部非线性证书和显式的 `Kp,Kd` 充分选值。这比原 `texdocs` 只对 twist 输出给 L2 界的结果多出位姿输出，也让 `Kp` 进入 Gamma 设计。然而四 Gamma 是**两行共享输入预算的双输出指标**，不是四个独立外扰输入的增益矩阵。

该结果不等于最优 H∞ 综合。以平移线性化通道为例，`T/d_v=1/(s²+b_v s+p_T)`、`v/d_v=s/(s²+b_v s+p_T)`；后者的真实 H∞ 范数恰为 `1/b_v`，与 `p_T>0` 无关。当前公式 `b_v=2/gamma_(v,xi)` 因而给单独 twist 指标留了两倍阻尼。Schur 补对**所选储能函数与供给率**是精确的，但储能函数和 `b=2/gamma_xi` 本身是人为的充分选择。若说“最优”或“最紧”，必须提供全系统下界或受约束 Pareto 最优性证明。

此外，`Kp` 并非仅由四个 Gamma 确定：显式公式还含工作域常数 `eta_0` 与 `bar omega`。这不是错误，但论文必须写成“**固定工作域后的 Gamma 到增益映射**”。零初值的无穷时域 L2 界还需要有限能量扰动不使轨迹出域；只假定轨迹留域不能算作对物理闭环的完整保证。当前推导附录 A 有能量留域条件，可纳入主定理假设。

## 若仅做 L2/H∞，建议怎样形成可投稿主张

建议把候选贡献压缩为一个精确命题：**对给定的关节力矩有限能量扰动及正则工作域，基于 DQ 的计算力矩控制同时保证姿态/平移位姿与 twist 的四项 L2 误差预算，并可由预算反算 `Kp,Kd`，同时给出闭环留域与输入可行条件。** 力矩到 `d` 的 `JM^{-1}` 映射和四个输出的不同单位/权重须明确写入指标；如果考虑惯量误差，反馈相关的扰动不能先假定为外生 L2，必须作有限区间的小增益闭合。这里仍然只讨论 L2，无须加入 L∞ 结果。

投稿前至少完成以下核验：

- 取得 [4]、[5] 全文，逐项对照其误差、输入扰动、储能函数、性能输出与增益设计；特别检查 [5] 是否已有 L2/H∞ 定理。未完成前不写“首次”。
- 与 [3] 的 DQ 加速度控制及 [5] 的 DQ 鲁棒计算力矩控制做同样带宽、峰值力矩及初始姿态的公平比较；[2] 只作为速度级理论参照，不能把它的速度扰动 Gamma 与力矩 Gamma 直接数值比较。
- 注入幅值与时长已知、确属 L2 的力矩扰动，报告四路 `||输出||_L2 / ||输入||_L2`、各自 Gamma 余量、最大力矩和工作域边界；仅画自然跟踪误差不能检验 H∞ 证书。
- 与标准二阶通道的真实 H∞ 范数比较证书保守性，解释使用 DQ 结构后具体省掉了哪一项保守界，或增加了哪一项非线性保证。

**定位判断：** 若只保留当前四 Gamma 充分公式与仿真，作为高水平控制理论论文的独立创新点偏弱；若完成以上闭环力矩输入证明、紧性比较和可重复实验，可定位为具有明确新性能保证的 DQ 机械臂控制设计论文。高阶 TODQ/HDQ 运动学若保留在同篇，可作为另一项独立贡献，但不能替代 L2 控制器与上述直接竞争工作的比较。
