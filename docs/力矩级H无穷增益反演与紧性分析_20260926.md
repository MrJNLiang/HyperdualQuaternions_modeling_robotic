## 0. 结论速览

1. **扭转弯道（d → e_ξ）的反演零放缩损失**：认证增益 γ\* = 1/λ_min(K_d)（定理 3(c′)）同时是
   （i）证书族内最优（AM–GM 在反演点取等），
   （ii）线性化通道的真实 H∞ 范数（‖s/(s²+k_d s+k_p)‖∞ = 1/k_d 精确，数值验证 ratio = 1.000000），
   （iii）Lyapunov 恒等式的精确可行性包络（初值项时域精确：‖e_ξ‖₂² = V(0)/λ，验证值 1.000000）。
2. **位姿通道（d → e_z）**：频域两支闭式对线性化通道**精确**（无不等式，误差 ≤ 网格分辨率）；全局 ISS 版含一处实质性三角拆分保守（IC 与扰动峰假设同时）。
3. **真正的保守不在证书常数，在扰动簿记**：σ_max(J) 输入映射、阻尼伪逆残差（奇异向附近 → 1）、D̄ 预算、(5.7) 的有限 α 档。文档 §4 给出逐步账本。
4. **速度级 C3 的 √2 不是不等式松弛**：[P2] 证书对堆叠输入 (v_w; v_c) 精确取等（验证 stacked = γ 精确）；若把同一 γ 读作合并扰动 d = v_w + v_c 的增益则差 √2 倍。力矩级 3(c) 是单输入约定，无此二义性。

## 1. 记号与通道模型

误差系统（定理 3(a)，式 (5.5)）：

$$
\dot e_z=A(\tilde x)\,e_\xi,\qquad
\dot e_\xi=-K_d e_\xi-A^{\top}(\tilde x)\,K_p\,e_z+d(t),
\qquad d=J\,w_{\mathrm{dyn}}\;(\text{按 }(5.1d)\text{ 再分解})
$$

存储函数（式 (5.4a)）：V = ½‖e_ξ‖² + ½ e_z^T K_p e_z。**A^T 整形使交叉项精确相消**：

$$
\dot V \;=\; e_\xi^{\top}\bigl(-K_d e_\xi - A^{\top}K_p e_z + d\bigr) + e_z^{\top}K_p A e_\xi
\;=\; -\,e_\xi^{\top}K_d\,e_\xi \;+\; e_\xi^{\top}d
\tag{★ 恒等式}
$$

对任意对称 K_p 精确成立（gain_design.py 模块注释同款）。近恒等线性化 A₀ = diag(−½I₃, I₃) 下两通道解耦（`gain_design.c1_channels` 同款常数）：

| 通道 | ODE | 输入系数 | 刚度 | 扭转输出 | 位姿输出 |
|---|---|---|---|---|---|
| 旋转 | Ö + K_ω Ȯ + (p_O/4) O = −d_ω/2 | −1/2 | p_O/4 | ω̃ = −2Ȯ | O |
| 平移 | T̈ + K_v Ṫ + p_T T = +d_v | +1 | p_T | ṽ = Ṫ | T |

γ 的量纲：扭转 γ\* 单位 **s**（加速度扰动 → 速度误差）；位姿 γ_z 单位 **s²**（加速度扰动 → 位姿误差）。

## 2. 扭转弯道反演 → K_d

### 2.1 论文证书族与 Schur 判据

定理 3(c)：点态耗散不等式 V̇ ≤ −(1/2κ)‖e_ξ‖² + (γ_a²/2)‖d‖² 对任意 (e_ξ, d) 成立的**充要**条件

$$
M=\begin{bmatrix}K_d-\tfrac{1}{2\kappa}I_6 & -\tfrac12 I_6\\ -\tfrac12 I_6 & \tfrac{\gamma_a^2}{2} I_6\end{bmatrix}\succeq0
\;\Longleftrightarrow\;
K_d\succeq\tfrac12\bigl(\kappa^{-1}+\gamma_a^{-2}\bigr)I_6
\tag{5.6a}
$$

认证增益 γ\* ≜ γ_a√κ，积分得 (5.6)：κ⁻¹∫‖e_ξ‖² ≤ γ_a²∫‖d‖² + 2V(0)。

### 2.2 族内最优（定理 3(c′)）

(i) AM–GM：任一可行点 γ\* = γ_a√κ ≥ 1/λ，λ ≜ λ_min(K_d)；(ii) 反演点 (κ, γ_a) = (λ⁻¹, λ^{−1/2}) 可行且取等：

$$
\gamma^{*}_{\mathrm{opt}}=\frac{1}{\lambda_{\min}(K_d)}
\tag{5.6c}
$$

即**认证目标 γ\* ⟺ K_d ⪰ (1/γ\*)I₆**。与 `screen()` 的衔接：C-cert 检查的 level = ½(κ⁻¹+γ_a⁻²) 在反演点恰为 **1/γ\***——反演点把 (5.6a) 的 AM–GM slack 恰好收满，非最优 (κ, γ_a) 的 slack 不出现在反演规则里。

### 2.3 真实范数 = 1/k_d（紧性核心）

线性化通道 d→ω̃ 传递函数 s/(s²+k_d s+k_p) 的 H∞ 范数有精确闭式：|s/(…)|² 在 ω = √k_p 处取最大（令 u = ω² 求导，驻点 u = k_p 唯一），峰值 = 1/k_d，**与 k_p、ζ 无关**——速度共振。数值验证（§5-A）：五种 (k_d, k_p) 组合 ratio 均 = 1.000000。

推论：
- **各向同性块**（K_ω = k_ωI₃ 等）：1/λ_min(K_d) = max_i 1/k_d,i = 真实 MIMO 范数，**零间隙**。
- **可交换各向异性块**（K_ω、K_{p,O} 对称且可同时对角化）：逐特征方向解耦，仍然取等。
- **非交换各向异性**：1/λ_min 只是上界（与 3(c) 后 Remark、附录 C.7 一致）。数值样本：强各向异性非交换 gap = **2.53%**；近各向异性（±5% 失配）gap ≈ **0.00%**。实务上 shipped 的各向同性设计无此损失。
- 时域佐证（§5-G）：共振输入 ‖e_x‖₂/‖d‖₂ = 0.1242 → 1/k_d = 0.125（有限窗）；慢输入仅 0.0185（证书是最坏情形保证，不是典型性能预测）。

### 2.4 反演规则

$$
\boxed{\;K_\omega = \frac{1}{\gamma_\omega}I_3,\qquad K_v=\frac{1}{\gamma_v}I_3\;}
$$

全局 6D 版：K_d = γ\*⁻¹I₆（单旋钮）。注意与速度级 C3 的对照：C3 的 k = √2/γ 对应堆叠输入约定（§4-账本第 11 条），力矩级单输入约定下常数就是 1/k_d，无 √2。

## 3. 位姿通道反演 → K_p（本文档新增；论文 3(c) 明示"此界只约束 e_ξ"）

### 3.1 频域两支闭式（线性化通道内精确）

d→O 传递函数 (1/2)/(s²+k_ω s+p_O/4)，d→T 为 1/(s²+k_v s+p_T)。先给标准通道 1/(s²+k_d s+k_p) 的位置峰值（精确闭式，§5-B 验证 max err 2.9e−6）：

$$
\left\|\frac{1}{s^2+k_ds+k_p}\right\|_\infty=
\begin{cases}
\dfrac{1}{k_p}, & k_d^2\ge 2k_p\ (\zeta\ge\tfrac{1}{\sqrt2})\\[6pt]
\dfrac{2}{k_d\sqrt{4k_p-k_d^2}}, & k_d^2<2k_p
\end{cases}
$$

代入通道常数并反解 k_p（给定 k_d = 1/γ_twist 与目标 γ_pose）：

**旋转**（γ_O 对 d_ω → O）：

$$
\gamma_O\begin{cases}
\ \ge\ \gamma_\omega^2 &\Rightarrow\ p_O = 2/\gamma_O \quad(\text{过阻尼支},\ \zeta_O=k_\omega/\sqrt{p_O}\ge 1/\sqrt2)\\[4pt]
\ <\ \gamma_\omega^2 &\Rightarrow\ p_O = k_\omega^2 + \dfrac{1}{(k_\omega\,\gamma_O)^2}\quad(\text{欠阻尼支})
\end{cases}
$$

**平移**（γ_T 对 d_v → T）：

$$
\gamma_T\begin{cases}
\ \ge\ 2\gamma_v^2 &\Rightarrow\ p_T = 1/\gamma_T\\[4pt]
\ <\ 2\gamma_v^2 &\Rightarrow\ p_T = \dfrac{1}{4}\Bigl(k_v^2+\Bigl(\dfrac{2}{k_v\gamma_T}\Bigr)^2\Bigr)
\end{cases}
$$

两支在开关点连续（旋转 γ_O = γ_ω² ⟺ p_O = 2k_ω² ⟺ ζ_O = 1/√2；平移同理），往返反演精确（§5-C/D：max err ≤ 1.2e−7）。设计换算：ω_n,O = √p_O/2、ζ_O = k_ω/√p_O。

与 `screen()` C-damp（ζ ≥ 1）的相容子族：**γ_O ≥ 2γ_ω²、γ_T ≥ 4γ_v²**（均落在过阻尼支内）。

数值例：γ_ω = 0.2 → k_ω = 5；γ_O = 0.02 < γ_ω² → p_O = 25 + 100 = 125（ω_n = 5.59, ζ = 0.447）；回代峰值 1/(5·√100) = 0.02 ✓。γ_v = 0.1 → k_v = 10；γ_T = 0.015 < 2γ_v² → p_T ≈ 69.4（ζ = 0.6）✓。

### 3.2 全局 L2 预算版（ISS 语义，不依赖线性化）

沿 (★)，用逐点紧配方 −λe² + |e||d| ≤ d²/(4λ)（λ = λ_min(K_d)，e = d/(2λ) 处取等）：

$$
V(T)\;\le\;V(0)+\frac{\|d\|_{L_2(0,T)}^2}{4\lambda}
$$

在 e_z 的内点极值处 e_ξ = A⁻¹ė_z = 0（A 在水平集 (5.5b) 上一致可逆，(5.5c) 给出 η̃ 下界），故 V 在该时刻只含位姿项：

$$
\|e_z\|_\infty\;\le\;\sqrt{\frac{2V_{\max}}{\lambda_{\min}(K_p)}}
\;\le\;\sqrt{\frac{2V(0)}{\lambda_{\min}(K_p)}+\frac{\|d\|_{L_2}^2}{2\,\lambda\,\lambda_{\min}(K_p)}}
$$

分块各向同性 K_p 时初值位姿项**自消**（2V_ω(0)/p_O = ‖O_0‖² + ‖ω̃_0‖²/p_O），得纯扰动驱动条件：给定扰动能量预算 D̄ 与位姿认证 γ_z，

$$
\boxed{\;p \;\ge\; \frac{\gamma_x\,\bar D^2}{2\,\gamma_z^2}\;}\qquad(\gamma_x=1/\lambda\ \text{为扭转认证值})
$$

### 3.3 两种证书语义的选择

| | 频域峰值版（§3.1） | L2 预算版（§3.2） |
|---|---|---|
| 语义 | ‖G_{d→e_z}‖∞ ≤ γ_z | ‖e_z‖∞ ≤ γ_z 给定 ‖d‖_{L2} ≤ D̄ |
| 范围 | 近恒等线性化 | 全局（水平集前提 (5.5b)/(5.5c)） |
| 保守性 | 仅线性化本身 | 三角拆分 + D̄ 簿记 |
| 适用 | w_dyn 有界幅值 + 可能共振激励 | w_dyn 有界能量 |

论文写法建议：位姿通道 γ 在恒等邻域取频域紧值、全局取 L2 预算值，两层证书并列。

## 4. 紧性账本（逐条放缩审计）

| # | 步骤 | 性质 | 间隙 | 依据/验证 |
|---|---|---|---|---|
| 1 | V̇ 恒等式 (★) | **精确** | 0（对已定义的 d） | A^T 整形；代价：伪逆残差/线性化余项全部吸收进 d（诚实性备注），d 的实际大小由 §4-8 簿记决定 |
| 2 | Schur 判据 (5.6a) | **充要** | 0 | 边界 k_d = level 时 λ_min(M) = 0 精确（§5-F） |
| 3 | AM–GM（3(c′)(i)） | 仅非最优点有 slack | 反演点取等 | (κ,γ_a)=(γ\*,√γ\*) 时 level = 1/γ\* |
| 4 | 证书 1/λ vs 真实范数 | 各向同性/可交换**取等**；非交换为上界 | 0 / ≈2.5%（强各向异性非交换样本） | §5-A/H（速度共振、MIMO 奇异值） |
| 5 | 配方 −λe²+ed ≤ d²/(4λ) | **逐点紧** | 0（e = d/(2λ) 取等） | 初等 |
| 6 | Cauchy–Schwarz ∫e·d | 最坏情形紧 | 仅中间段可能微小 | H∞ 最坏扰动与 e 同相；两端（D=0、D→∞）精确 |
| 7 | 三角拆分 2V ≤ 2V(0) + D̄²/(2λ) | **实质性保守** | IC 与扰动峰不同时达到 | 仅 §3.2 ISS 语义；频域路线无此项 |
| 8 | 输入簿记 d = J w_dyn + (I−JJ⁺)u_task | **保守（实务最需注意）** | σ_max(J) 上界；奇异向附近残差 → 1 | λ 与 γ 在此耦合：γ 预算隐含 σ_max(J)‖w_dyn‖ + ‖u_task‖λ²/(σ_min²+λ²) ≤ 允许值 |
| 9 | 近恒等常数（1/2、1/4） | 线性化局部精确 | 全局靠 (5.5b)/(5.5c) 水平集约束 A 条件数 | `gain_design.py` 模块注释 |
| 10 | (5.7) RMS 界的有限 α 档 | α→0 极限紧；有限 α 最松 | λ_eff、D 均为乘积放缩 | 定理 3(d)；需要 α < λ_min/λ_max（条件数约束） |
| 11 | 速度级 C3 的 √2 | **约定代价，非松弛** | 对堆叠输入精确取等 | [P2]：κ=√2/γ 时 stacked ‖[h,h]‖∞ = γ 精确（§5-E）；合并输入 d = v_w+v_c 的真实增益 = 2/κ = √2·γ |

第 11 条展开（本轮分析的新发现）：[P2] 把 v_w（模型残差）与 v_c（数值/前馈残差）视为**两个正交输入通道**，证书 ‖O‖₂ ≤ γ·‖(v_w;v_c)‖₂ 在 κ = √2/γ 下精确取等——对它自己的约定零损失。但若把同一 γ_O 读作合并物理扰动 d = v_w + v_c 的 L2 增益，真实最坏增益是 2/κ = √2·γ_O：读法差 √2（3 dB）。力矩级 3(c) 从一开始就是单输入 d，γ\* = 1/λ 对合并输入即紧，**没有这层二义性**。若论文对比需要在同一语义下讨论两代律，建议统一按"单输入 L2 增益"口径，并把 C3 的 γ_O 注明为堆叠约定。

**总评**：证书常数链条（#1–#6）零放缩损失；会"放缩太多"的地方只有三处——#7（ISS 语义，可改用频域语义规避）、#8（扰动簿记，只能靠实测 ‖J‖ 与残差预算收紧）、#10（有限 α，可报 α→0 极限值）。#4 的非交换间隙在 shipped 各向同性设计下不存在。

## 6. 反演实现（与 `gain_design.py` 接口）

```python
import numpy as np

def invert_gamma(gamma_w, gamma_O, gamma_v, gamma_T):
    """C1 通道常数（gain_design.c1_channels 同款）：旋转输入 1/2、刚度 p_O/4；
    平移输入 1、刚度 p_T。返回 (K_d 6x6, K_p 6x6)，可直接进 gains_to_matrices 同构路径
    与 screen()（反演点处 C-cert 的 level 恰为 1/gamma_twist）。"""
    k_w = 1.0 / gamma_w                                   # 扭转通道精确: gamma = 1/k_d
    p_O = (k_w**2 + 1.0/(k_w*gamma_O)**2 if gamma_O <= gamma_w**2
           else 2.0 / gamma_O)
    k_v = 1.0 / gamma_v
    p_T = ((k_v**2 + (2.0/(k_v*gamma_T))**2) / 4.0 if gamma_T < 2.0*gamma_v**2
           else 1.0 / gamma_T)
    K_d = np.diag(np.r_[np.full(3, k_w), np.full(3, k_v)])
    K_p = np.diag(np.r_[np.full(3, p_O), np.full(3, p_T)])
    # 隐含参数: 旋转 omega_n=sqrt(p_O)/2, zeta_O=k_w/sqrt(p_O); 平移 wn=sqrt(p_T), zeta=k_v/(2 sqrt(p_T))
    return K_d, K_p
```

γ-sweep 协议：扫 (γ_ω, γ_O, γ_v, γ_T) 网格 → 每点反演为 (K_d, K_p) → 现有 budget-matched 框架，同时输出三条证书曲线：Lyapunov 界（全局）、通道峰值闭式（局部精确）、coprime margin / ν-gap（固定结构裕度，McFarlane–Glover 1990 / Vinnicombe 2001）。律 (5.2) 与其 A^T 整形、精确抵消结构一字不动。

## 7. 多通道组织

1. **单标量 γ**：K_d = γ⁻¹I₆, K_p = pI₆。由 (★) 与 ‖A₀‖ = 1，耦合不需要单独处理。
2. **分通道 4 个 γ（推荐）**：(γ_ω, γ_O, γ_v, γ_T) → 块对角 (K_d, K_p)，落在定理 3(c-2) 要求的结构内（平移刚度块各向同性的必要性见附录 C.3）。
3. **矩阵加权**：逐轴不同 γ_i → K_d 第 i 对角元 = 1/γ_i。只有追求"耦合 + 非对角增益下最优"才需要 polytopic bounded-real LMI + Y = K_d·P 代换；本结构 Lyapunov 函数被 K_p 固定，LMI 无额外收益。
