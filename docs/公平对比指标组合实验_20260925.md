# 公平对比指标与预算锚点实验报告

**对比对象**：本文几何一致计算力矩律（式 5.2，下称 **C1**） vs 三个基线
**日期**：2026-09-25
**代码**：`TNDQ_sim/experiments/compare_metrics_portfolio.py`（第一轮）、
`TNDQ_sim/experiments/compare_budget_matched.py`（第二轮）
**数据**：`TNDQ_sim/results/metrics_portfolio*.csv`、`budget_matched*.csv`

## 0. 摘要

报告回答两个问题：

1. **对比两个控制律时，哪些"努力/性能"指标是公平且有分辨力的？**
   结论：在重力全补偿的机械臂上，"力矩从 0 到 T 积分"一族（∫τdt、∫‖τ‖₁dt、
   ∫‖τ‖²dt）几乎不含控制律信息（四律差异 <0.1%），必须换成**以重力为参考的
   努力** ∫‖τ−g‖²dt、**力矩变化率** RMS‖τ̇‖、**峰值/饱和占比**，且必须与
   性能指标（IAE、调节时间）成对读取。
2. **在哪种公平性协议下，C1 的优势能够显形？**
   结论：**等努力锚点**（∫‖τ−g‖²dt 或 ∫‖q̈_ref‖²dt 差 1% 以内）与**等精度
   锚点**（IAE 达到 C1 标称值的 90%）两种协议互相印证：在测量噪声下 C1 的
   力矩抖振比 C3 低 **14 倍**、非重力努力低 **1.6–1.7 倍**（精度相同）；在
   大误差调节下 C2 完全不收敛（IAE 为 C1 的 150–170 倍）、C3 需 2.3–2.5 倍
   努力且峰值力矩饱和；C1 的饱和/安全治理器触发率在全部工况中最低。
   以 ∫‖τ‖²dt 为锚点是**反面教材**：它对增益相差 4 倍不敏感，会制造假公平。

## 1. 被控对象与共享控制栈

### 1.1 机器人与动力学模型

被控对象为 KUKA LBR4+ 七自由度机械臂（标准 DH 表见 `config/params.py::KUKA_LBR4_DH`，
连杆质量 [2.7, 2.7, 2.7, 2.7, 1.7, 1.6, 0.95] kg，电机折算惯量
B = diag(1.20, 1.20, 0.80, 0.80, 0.30, 0.30, 0.15) kg·m²）。对象端"真值"动力学为
RNEA 刚体模型 + 关节摩擦：

$$
M(q)\,\ddot q + C(q,\dot q)\,\dot q + g(q) \;=\; \tau + \tau_{ext}, \qquad
\tau_f = B_v\,\dot q + T_c\,\tanh\!\big(\dot q / \dot q_0\big) \in \tau_{ext}
$$

摩擦参数（显式不确定性假设，非厂商辨识值）：B_v = [0.35, 0.35, 0.25, 0.25, 0.12, 0.08, 0.06] N·m·s/rad，
T_c = [1.20, 1.20, 0.80, 0.80, 0.35, 0.22, 0.16] N·m，q̇₀ = 0.02 rad/s。

数值积分：半隐式欧拉，步长 **dt = 1 ms**。力矩限幅
τ̄ = [176, 176, 100, 100, 100, 38, 38] N·m；关节限位 ±170°/±120°（奇/偶关节）。

### 1.2 四条控制律共享的部分（公平性约束）

四条律走**同一条控制栈**，只有"控制律"方框不同：

```
(q,q̇) ─→ FK 层(TNDQ链, 式3.4/3.5) ─→ 误差层(定理1/2) ─→ 【控制律】→ q̈_ref
         ─→ 零空间投影 ─→ ‖q̈_ref‖≤40 rad/s² 限幅 ─→ 关节安全治理器
         ─→ 力矩出口 τ = M̂ q̈_ref + Ĉ q̇ + ĝ ─→ 力矩限幅 ─→ 对象
```

- **同一力矩出口**：τ = M̂q̈_ref + Ĉq̇ + ĝ（式 5.2 名义模型，控制器侧 M̂/Ĉ/ĝ 与
  对象同参数，mismatch 工况除外）——对比的是律，不是执行接口；
- 同一阻尼伪逆 J⁺ = Jᵀ(JJᵀ+λ²I)⁻¹，λ = 10⁻⁶（σ_min(J) < 10⁻³ 时升到 5×10⁻²）；
- 同一零空间冗余消解 q̈_ref ← q̈_ref + N[4(q_c−q) − 4q̇]，N = I − J⁺J，q_c = 初始位形；
- 同一指令限幅（‖q̈_ref‖ ≤ 40 rad/s²）与安全治理器（超速制动 25 rad/s²、
  限位预测制动，缓冲 0.08 rad）；
- 误差层统一用 HDQ 误差：x̃ = x x_d*，e_ξ = 2ẋ̃x̃*，e_z = [O; T]，
  O = −Im(r̃)，T = p(x̃)，A(x̃) 同定理 2（式 4.5）。

## 2. 对比的四条控制律（公式与增益）

记号：ξ_d、ξ̇_d 为期望拧转/拧转速率（TNDQ 期望链 σ¹/σ² 通道解析给出，式 3.5）；
J 为几何雅可比；J̇q̇ 由 TNDQ 链免构造读出（式 3.5）。

### C1 —— 本文律（式 5.2，几何一致计算力矩）

$$
\ddot q_{ref} = J^{+}\Big( \underbrace{\mathrm{vec}_6\!\big(\mathrm{Ad}_{\tilde x}\,\dot\xi_d + \mathrm{ad}_{\tilde\xi}\,\mathrm{Ad}_{\tilde x}\,\xi_d\big)}_{\text{前馈(引理1)}} \underbrace{- K_d\, e_\xi - A^{\!\top}\!(\tilde x)\, K_p\, e_z}_{\text{反馈}} \underbrace{-\ \dot J q̇}_{\text{补偿}} \Big)
$$

增益（params.GAIN_SETS["tuned"]）：K_d = diag(24·I₃, 24·I₃)，K_p = diag(320·I₃, 80·I₃)。

### C2 —— 忠实 [Chandra+2020] resolved-acceleration 律

[Ch20] 式 (32)–(35)+(2) 的忠实移植；与 C1 的**唯一结构差异**是位姿反馈用
screw-log 整形（d/dt vec6(2 ln x̃) 在 φ=π 处奇异）而非 A^T 整形：

$$
a_{cmd} = \mathrm{vec}_6\big(\mathrm{Ad}_{\tilde x}\dot\xi_d + \mathrm{ad}_{\tilde\xi}\mathrm{Ad}_{\tilde x}\xi_d\big) + K_v\,\omega_e - K_P\,\mathrm{vec}_6\!\big(2\ln \tilde x\big), \qquad
\ddot q_{ref} = J^{+}\big(a_{cmd} - \dot J q̇\big)
$$

其中 ω_e = Ad_{x̃}ξ_d − ξ = −e_ξ（[Ch20] 式 32 的搬运拧转误差）。
增益：K_v = 24·I₆，K_P = 80·I₆。（符号约定按本仓库右不变误差 x̃ = x x_d* 换向，
闭合回路符号已由 tests/test_math_properties.py 的 oracle 核验。）

### C2-abl —— 朴素二阶消融律（不对应已发表理论）

消融 C1 的全部结构：无 Ad 输运、无 A^T 整形、ξ̇_d 与 J̇q̇ 用**后向差分**：

$$
u_{task} = \dot\xi_d^{\,num} + K_d\,(\xi_d - \xi) + \begin{bmatrix} p_O\, O \\ -\,p_T\, T \end{bmatrix} - (\dot J q̇)^{num}, \qquad
\ddot q_{ref} = J^{+} u_{task}
$$

增益：K_d = 24·I₆，p_O = 160，p_T = 80。

### C3 —— 一阶 DQ H∞ 运动学律（前仓库"上一代理论"）+ 内环速度伺服

速度级指令经内环桥接到同一力矩接口：

$$
\dot q_{cmd} = J^{+}\Big( \begin{bmatrix} k_O O \\ -k_T T \end{bmatrix} + \mathrm{vec}_6\big(\tilde x\,\xi_d\,\tilde x^{*}\big) \Big), \qquad
\ddot q_{ref} = \frac{\dot q_{cmd} - \dot q_{cmd}^{prev}}{\Delta t} + K_{servo}\big(\dot q_{cmd} - \dot q\big)
$$

增益：k_O = √2/γ_O = 8，k_T = √2/γ_T = 4，K_servo = 20 s⁻¹，基线伪逆阻尼 10⁻³。
C3 没有 e_ξ 阻尼通道、没有解析 ξ̇_d/J̇q̇（前馈差分一拍滞后）。

### 第一轮增益协议：线性化配平

四条律的增益按近恒等线性化**逐通道配平**：误差通道二阶模型
旋转通道 Ö + K_ω Ȯ + (p_O/4)O = −d_ω/2、平移通道 T̈ + K_v Ṫ + p_T T = d_v
配置到相同极点 {−4, −20} s⁻¹、相同直流刚度 80（C2/C3 通道系数差一个
log 映射/½ 因子，已在上表增益中折算）。**配平后标称行为几乎相同是协议的
预期结果**（见 §6.1），因此第二轮改用预算锚点匹配（§5.2）。

## 4. 指标定义与计算公式

**约定**（适用于本报告所有表格与 `results/*.csv`）：

- T 为仿真时程；τ(t) 为**限幅后实际下发的关节力矩**；q̇(t) 为对象端真实关节速度；
  q̈_ref(t) 为控制律输出（经限幅/治理器后的指令）；
- 误差信号由相对位姿误差 DQ x̃ = x x_d* 定义：

$$
\varepsilon_p(t) = \|T(t)\|_2 \quad(\text{位置误差范数，}T = p(\tilde x)), \qquad
\varepsilon_\theta(t) = 2\,\mathrm{atan2}\big(\|\mathrm{Im}\,\tilde r(t)\|,\ \tilde\eta(t)\big)\ \ (\text{旋转误差角})
$$

  （T 是相对位姿误差 DQ 的平移部分，含旋转-平移耦合，不是两端点位置差；与仓库其他实验口径一致。）
- **采样口径**：力矩类指标在每个积分步累计（Δt = 1 ms）；误差类指标在每个
  **控制步**采样（Δt_ctrl = 1 ms，coarse-dt 工况为 5 ms）；稳态窗 W_ss 见 §3.1
  场景表（circle [6,10] s，line/large [5,8] s）；
- 所有指标均为 **lower-is-better**；"CSV 列名"是 `results/*.csv` 中的字段名。

### 4.4 哪些指标是退化的（负结果，同样重要）

在重力全补偿的机械臂上，τ ≈ g(q) 是不随控制律变化的巨大基座项
（circle/nominal 实测：E_∇g 仅占 E_{τ,2} 的 **0.24%**）：

| 指标 | 四律实测（circle/none，相对差） | 判定 |
|---|---|---|
| I_τ（∫τdt，最自然的提案） | 579.4 / 579.5 / 579.5 / 579.1（差 0.07%） | **退化**：测的是机械臂不是律 |
| E_{τ,1} | 599.0 / 599.1 / 599.1 / 598.7 | **退化** |
| E_{τ,2} | 四律比值全部 1.000–1.002 | **近乎退化**：差异被约 200 倍大的重力基座淹没 |

推论：**任何含 g(q) 的力矩积分都不公平也无分辨力**；公平的力矩类指标必须
(i) 以重力为参考（E_∇g = ∫‖τ−g‖²dt），或 (ii) 取变化率/峰值/饱和（S_τ、τ_pk、
φ_sat）。此外，努力指标必须与性能指标成对读取——§6 中 C2 的 E_∇g = 0.68×C1
看似"最省力"，实际是它在大误差下卡死不动（见 §6.1 large 表）。

## 5. 公平性协议（两轮）

### 5.1 第一轮：线性化配平 + Pareto 扫描

四律增益按 §2 末尾配平（同极点 {−4,−20}、同直流刚度 80）。另做增益尺度扫描
λ ∈ {0.7, 1.0, 1.5}（λ 同乘各律全部反馈/位姿增益），在 (E_∇g, IAE_p^ss) 平面
检查 Pareto 支配。**结果：标称下四律几乎全平（差异 ≤2%）——这是配平的预期
结果，说明差异必须到应力工况找。**

### 5.2 第二轮：预算锚点匹配（1% 等预算）

放弃配平，改用**锚点匹配**：选锚点指标 B，取 B_ref = B(C1, λ=1)（circle/nominal
全时程），对每条律二分标定增益尺度 λ 使

$$
\Big| \frac{B(\lambda)}{B_{ref}} - 1 \Big| \le 1\%,
\qquad \lambda \ \text{同乘该律全部反馈/位姿增益}
$$

标定后**冻结** λ，跑工况矩阵。锚点集合与标定结果：

| 锚点 B | B_ref | C1 | C2 | C2-abl | C3 | 说明 |
|---|---|---|---|---|---|---|
| E_∇g（等努力） | 48.46 | 1.000 | 1.125 | 1.000 | 1.016 | C2 需 12.5% 更多增益才花掉同样努力 |
| E_q̈（等接口能量） | 46.33 | 1.000 | 1.125 | 1.000 | 1.016 | 结论与 E_∇g 一致 |
| IAE_p（**更严**等精度） | 0.9 × 0.0907 | 1.152 | 1.152 | 1.152 | 1.125 | 目标 = C1 标称 IAE 的 90%，四律全部参与标定（否则四律在 λ=1 处本就差 <2%，无信息量） |
| E_{τ,2}（退化锚点） | 19884.7 | 1.000 | **0.25** | **0.25** | **0.25** | 对 4 倍增益差不敏感 → 假公平 |

### 6.4 反面教材：以 E_{τ,2} 为锚点

E_{τ,2} 对增益完全不敏感（§4.4），基线在 **λ = 0.25（四分之一增益）** 就
"1% 达标"。矩阵里 C1 对基线的 IAE_p / IAE_p^ss / p_end 以 5/5 全胜——
这不是 C1 的优势，而是**锚点盲目制造出来的假优势**（增益差 4 倍的比较本身
不公平）。结论：∫‖τ‖²dt 不能作预算锚点，也不能单独作为努力指标。

## 7. 结论

### 7.1 C1 有优势的指标（建议写进论文）

1. **测量噪声 → 力矩抖振 S_τ**（最显著）：等预算、同精度下，C3 为 C1 的
   **14 倍**，C2-abl 为 1.15 倍，C2 为 1.13 倍（等努力下 C2 的 λ 被推高
   12.5%，抖振随增益上浮；配平增益时 C2 与 C1 持平）。机理：C1 的 ξ̇_d 前馈
   与 J̇q̇ 补偿是 TNDQ 链解析读出（式 3.5），C3/C2-abl 靠数值差分（一拍滞后
   + 差分噪声），经内环/力矩出口放大为执行器抖振。
2. **测量噪声 → 非重力努力 E_∇g**：C3 为 C1 的 **1.6–1.7 倍**（精度相同）。
3. **大误差调节收敛 t_s / IAE**：C2 因 screw-log 映射在近对拓区（φ→π）的
   d/dt vec6(2 ln x̃) 奇异，指令爆炸 → 治理器反复制动 → 卡死（IAE 150–170×、
   终端误差 0.53 m 不收敛）；C3 花 2.3–2.5× 努力且峰值力矩饱和。
   定量坐实论文 E4 差异点。
4. **安全裕度 φ_sat / φ_gov**：全部工况组合中最低（large 下 9.8% vs
   C2 73.7% / C2-abl 12.9% / C3 12.4%）。
5. **瞬态峰值**（max ε_p、max ε_θ）：多数工况最低。

### 7.2 C1 不占优的指标（如实报告）

1. **标称小误差跟踪精度**：配平或等预算下四律差 ≤2%，C2（λ 被推高 12.5%）
   与 C3 的 IAE 甚至略好 1–8%。log 律在远离奇异的小误差域本身是好律——
   C1 对 C2 的优势**只在大误差域**。
2. **纯调节（ξ_d≡0）收敛速度**：C2-abl 一直略快（t_s 0.57–0.59×）——ξ_d=0 时
   Ad 输运与 A^T 整形无处发挥；C2-abl 的缺陷（差分噪声、无证书）要靠
   noise/l2 工况暴露。
3. **经验 L2 增益 γ̂_ξ、γ̂_z 与 ISS 球**：配平后四律 ≈1.00（差异 <2%）。
   定理 3 的价值是**先验保证**（设计时即可声明 γ_a=0.5 的界与 ISS 球），
   不是经验增益优势——论文应这样表述，不要拿经验值横向比大小。
4. **nominal 力矩抖振**：C2 比 C1 平滑 7%。

### 7.3 对论文 §6 的方法论建议

- 努力指标三件套：**E_∇g = ∫‖τ−g‖²dt（重力参考）+ S_τ = RMS‖τ̇‖（抖振）+
  φ_sat/φ_gov（安全裕度）**；∫τdt、∫‖τ‖₁、∫‖τ‖² 在重力补偿臂上无分辨力，不用。
- 性能指标三件套：**IAE（稳态窗）+ t_s（5 mm/2° 带）+ 峰值**。
- 努力/性能必须成对出现，并声明配平/锚定协议。
- 公平性协议推荐组合：**等努力锚点（E_∇g）与等精度锚点（0.9×IAE）双协议**，
  二者在应力工况下结论一致即认为公平性成立。
- 结构差异只在**应力工况**可观测：noise（解析 vs 差分通道）、large（log 奇异）、
  mismatch/friction；标称下四律按构造趋同——任何"标称大幅领先"的表格都应
  优先怀疑配平不公。
