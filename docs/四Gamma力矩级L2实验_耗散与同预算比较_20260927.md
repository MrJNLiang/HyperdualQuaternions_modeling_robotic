# 四 Gamma 力矩级 L2 实验：耗散检验与同预算比较

## 本文主线与已完成范围

主线是将对偶四元数误差控制律的四个性能指标
\((\gamma_{\omega,z},\gamma_{\omega,\xi},\gamma_{v,z},\gamma_{v,\xi})\)
映射为 \(K_p,K_d\)，再把**关节力矩脉冲**经过实际动力学和雅可比映射到
\(d=[d_\omega;d_v]\)，分别检验旋转、平移双输出耗散式：

\[
\begin{aligned}
W_\omega(T)-W_\omega(0)+\int_0^T
\left(\frac{\|\mathcal O\|^2}{\gamma_{\omega,z}^2}
+\frac{\|\tilde\omega\|^2}{\gamma_{\omega,\xi}^2}
-\|d_\omega\|^2\right)dt&\le0,\\
W_v(T)-W_v(0)+\int_0^T
\left(\frac{\|\mathcal T\|^2}{\gamma_{v,z}^2}
+\frac{\|\tilde v\|^2}{\gamma_{v,\xi}^2}
-\|d_v\|^2\right)dt&\le0.
\end{aligned}
\]

本文完成两项：**(1)** 有限能量物理力矩脉冲下的逐时及积分耗散检验；
**(2)** 相同被控对象、四参数候选池和力矩预算下，C1 与 C2、C4 的实测权衡。
增益公式及证明见[两阶段多 Gamma 推导](两阶段多Gamma力矩级鲁棒推导_基于现有符号体系.md)式 (6)、(8)、(14)。
本实验只核验连续时间、精确匹配刚体模型的有限时长模拟，**不证明**采样、时延、丢包和模型误差下仍有相同 Gamma。

## 复现实验

在仓库根目录运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 TNDQ_sim/experiments/four_gamma_torque_study.py
```

脚本为 `TNDQ_sim/experiments/four_gamma_torque_study.py`；输出数据在
`TNDQ_sim/results/four_gamma_certificate.csv` 和
`TNDQ_sim/results/four_gamma_tradeoff.csv`，对应两张 PNG 与证书轨迹 NPZ。
固定随机种子；积分步长 0.005 s，时长 4 s；被控对象为仓库已有的 7 关节 LBR4 刚体动力学，关闭摩擦，使用同一力矩限幅和关节安全治理器。

### 1. 物理力矩输入与耗散量

由第一个构型的 \(M(q_0)J^+(q_0)\) 将指定任务空间方向映成固定关节力矩方向；
在 \(0.5\le t<1.5\) s 乘 \(\sin^2(\pi(t-0.5))\) 包络，故输入在有限时间外为零。
分别注入旋转、平移和两者混合方向。实测等效输入按

\[
d=J\ddot q-u_{\rm task},\qquad
d_{\rm phys}=JM^{-1}\tau_{\rm ext}
\]

计算。两者之差可检测伪逆残差或执行器限制是否偷换了扰动定义。
逐时残差使用推导式 (8) 的精确导数；积分残差另以每步实际状态重算 \(W\)，
因此不是对同一个代数表达式重复取值。离散残差只应按数值积分误差解释。

取工作域常数 \(\eta_0=0.8,\ \bar\omega=1\)，基准指标为
\((0.05,0.2,0.1,0.3)\)，顺序为
\((\gamma_{\omega,z},\gamma_{\omega,\xi},\gamma_{v,z},\gamma_{v,\xi})\)。
对应 \((b_\omega,b_v,p_O,p_T)=(10,6.667,77.292,14.806)\)。
另外对每个 Gamma 单独乘 0.75 和 1.25，共 9 组指标、3 种脉冲、27 条轨迹。
这里的 \(K_p,K_d\) 准确地说是 \(K(\gamma;\eta_0,\bar\omega)\)：
工作域常数预先固定，并非由 Gamma 推出。

| 检查项 | 27 条轨迹结果 |
|---|---:|
| \(\min\tilde\eta\) | 0.999960，大于 0.8 |
| \(\max\|\tilde\omega\|\) | 0.041321，小于 1 |
| \(\min\sigma_{\min}(J)\) | 0.118478 |
| \(\max\|d-d_{\rm phys}\|\) | \(3.00\times10^{-11}\) |
| 连续时间耗散残差的最大值 | \(-6.05\times10^{-32}\)；零扰动平衡段使最大值接近零 |
| 离散积分耗散残差的最大值 | \(7.88\times10^{-13}\)；数值误差量级 |
| \(\sqrt{E_{\rm out}/E_d}\) 的最大值，旋转 / 平移 | 0.585 / 0.642；仅统计有非零输入能量的通道 |
| 饱和 / 加速度限幅 / 安全治理器 / 越限 | 均为 0 |

混合脉冲使 \(\max|\mathcal T^\top(\tilde\omega\times\tilde v)|=6.07\times10^{-7}\ne0\)，
因此也检验了平移耗散式的几何耦合项。以上结果支持代码与连续时间证书的一致性，
但当前轨迹离 \(\tilde\eta=0.8\) 和 \(\|\tilde\omega\|=1\) 边界很远；
\(0.585/0.642\) 是这组输入下的比值，不是诱导范数或证书紧性估计。

### 2. 相同力矩预算的四参数比较

C1 是本文的 \(-A^\top K_pe_z\) 律；C2 是 Chandra 等的单位对偶四元数
resolved-acceleration 螺旋对数反馈；C4 是解耦的四元数向量/平移 PD 消融基线。
三者共享期望轨迹、前馈、\(J^+\)、刚体对象、力矩出口、限幅和积分器。
旋转/平移比例与微分增益共 4 个自由度；对同一参数向量匹配恒等位姿附近的局部刚度和阻尼。

参数候选是 17 组四 Gamma 反演值（基准、单参数 ±25%、8 组联合扰动）加
8 组共享的独立四增益样本，共 25 组**相同参数向量**供每条控制律使用。
后一类 C1 样本只用于结构公平比较，不声称满足式 (14) 的证书。
跟踪任务为 2 s 的 8/5/-4 cm 直线位移与 0.3 rad 旋转，4 s 内施加同一个混合有限能量关节力矩脉冲。

统一预算以 C1 基准点为参照：

\[
\int_0^4\|\tau_{\rm cmd}-g(q)\|^2dt\le 1.01E_{\rm base}=10.6419,
\qquad
\max_{t,j}|\tau_{{\rm cmd},j}-g_j(q)|\le1.05P_{\rm base}=3.59295.
\]

还要求无力矩饱和、加速度限幅、安全治理和关节越限。75 条轨迹中，
每条控制律各有 15/25 组符合预算；C1 的合格组中 11 组由四 Gamma 公式反演。
实际峰值预算没有成为筛选瓶颈，主要起作用的是非重力力矩能量上限；
这是一种**共同上限**比较，不是各方法逐条精确配平能量。

| 基准参数 | C1 | C2 | C4 |
|---|---:|---:|---:|
| 位置 IAE (m s) | 0.017442 | 0.017436 | 0.017442 |
| 姿态 IAE (deg s) | 0.687289 | 0.687278 | 0.687281 |
| 非重力力矩平方积分 | 10.5365 | 10.5415 | 10.5365 |

25 对同参数样本中，C2 与 C1 的最大相对差为位置 IAE 0.090%、姿态 IAE 0.0026%；
C4 与 C1 的位置 IAE 基本重合，姿态 IAE 最大相对差 0.0022%。
四指标 Pareto 标记会受这些极小差别影响，不能据此宣称某一律占优。
**本工况没有显示 C1 的可观测跟踪优势**；实证贡献是四 Gamma 对
\(K_p,K_d\) 的可验证映射及其力矩扰动耗散保证。

四 Gamma 的调参确实改变实际权衡：例如 C1 取
\(\gamma_{\omega,\xi}=0.75\gamma_{\omega,\xi}^{\rm base}\) 时，
\(b_\omega\) 从 10 增至 13.333、\(p_O\) 从 77.292 增至 113.102，
姿态 IAE 从 0.6873 降至 0.4723 deg s，仍符合预算。
将 \(\gamma_{v,z}\) 缩至 0.75 倍使位置 IAE 从 0.01744 降至 0.01248 m s，
但能量升至 10.739，超过共同预算。Gamma 越小不保证在受限执行器下单调更好。

## 论文判断与边界

这两项实验完成了“物理力矩到等效扰动”和“相同四参数、相同预算比较”的第一轮核验。
其说服力仍限于匹配模型、无摩擦、无时延丢包、工作域中心附近的模拟。
实机上的建模差异与 WSL2 通信延迟没有被本次 L2 证书覆盖，
不能把实机可运行当成这些扰动仍满足同一 Gamma 的证据。
若论文声称 C1 的**性能**优于 C2/C4，目前数据不支持；
更准确的主张是“在近似相同的跟踪表现下，C1 给出了明确的四通道力矩级 L2 证书”。
要把该主张提升为强论文结果，下一步需要预先定义实机可测的输入/输出与工作域，
并检验模型失配、采样和时延是否仍落在所声称的扰动假设中。
