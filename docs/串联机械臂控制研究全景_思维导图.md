# 串联机械臂控制研究全景（TNDQ 视角）

## ① 上层轨迹规划方法

### 路径规划（几何层：只管形状）
- 关节空间路径：通过点插值、避奇异构型选择
- 笛卡尔空间路径：直线 / 圆弧 / 螺旋 ★（论文定点与圆周扰动、S3 抓杯直线轨迹）
- 避障规划：A*、RRT / RRT* / PRM、人工势场、CHOMP / TrajOpt
- 姿态规划：欧拉角插值有奇异 → 单位四元数 Slerp、对偶四元数插值（DualSCAD 等）★（DQ 插值与论文代数同源）

### 轨迹生成（时间层：给路径配上时间律）
- 多项式插值：三次 / 五次（quintic）/ 高阶
- 梯形 / S 曲线速度规划、jerk 限制轨迹（与 ③ 抑振在源头衔接）
- 样条类：贝塞尔、B 样条、通过点拟合
- 时间最优规划：TOPP / TOPP-RA（受速度、加速度、力矩约束）

### 规划-控制接口（决定下层能用什么信息）
- 时间参数化 / 在线时间缩放、在线重规划
- 通过点的平滑衔接（位置-速度-加速度三连续）
- 轨迹高阶导数完备性：计算力矩律需要任务空间加速度与 J̇q̇ ★（TODQ 一次连乘直接输出，规划端需保证足够光滑）
- 上层 MPC / 轨迹优化（非学习类）

## ② 基础动作控制（下层执行层）

### 控制结构与坐标选择
- 分层结构：电流环 → 速度环 → 位置环 / 力矩环
- 关节空间控制 vs 任务空间（操作空间）控制
- 二自由度控制：前馈 + 反馈

### 关节空间控制
- 独立关节 PID + 重力补偿
- 计算力矩控制（逆动力学控制）★（论文控制律的基准框架，Aᵀ-整形）
- 鲁棒控制：滑模 SMC、边界层 / 趋近律（抑抖 → ③）、有界控制

### 任务空间控制
- 速度级：逆雅可比 / 伪逆 / 加权最小二乘、零空间冗余分解
- 加速度级：Khatib 操作空间 PD + 补偿、任务优先级
- 误差参数化之争：欧拉角 / 轴角 / 四元数 / DQ / HDQ ★（论文核心：几何一致误差体系，一次乘法同时生成位姿 + twist 误差）
- 阻抗 / 导纳控制 ★（论文静态刚度标度律、TNDQ 增益整定）

### 力 / 力矩控制
- 关节力矩控制（直接力矩模式）★（7 自由度 KUKA LBR 力矩模式仿真）
- 力 / 位混合控制、显式力控制
- 柔顺交互：阻抗 / 导纳、最小关节模型

### 基础动作谱系（行业验收动作）
- 定点控制（调节问题）：刚度 / 阻尼成形 ★（定点与圆周扰动对比实验）
- 轨迹跟踪（时变参考）：前馈重要性、跟踪精度指标
- 绕轴运动 / 姿态机动：绕固定轴旋转、螺旋运动（screw）、DQ 对数映射 ★（螺旋对数导数在大误差处奇异正是论文动机之一）
- 组合动作：直线 / 圆 / 螺旋末端轨迹跟踪 ★（S3 抓杯）

## ③ 抖动消除（抑振）

### 软件侧
- 规划层（源头抑制）：jerk 连续轨迹、S 曲线、输入整形（ZV / ZVD）
- 控制层：滑模抖振抑制（边界层 / 高阶 SMC / 超螺旋）、低通与陷波（notch）滤波、相位补偿、增益整定 ★（TNDQ 增益整定与 C3 对比实验）
- 模型层：柔性关节 / 柔性连杆建模、摩擦建模与补偿（LuGre / Stribeck → 爬行抖动）、背隙与谐波减速器柔性补偿
- 估计层：扰动观测器 DOB、加速度反馈、卡尔曼类状态滤波

### 硬件侧
- 执行器：电机 - 减速比 - 惯量比匹配、直驱 vs 谐波 / RV
- 传动：预紧消隙、皮带 / 丝杠 / 联轴器刚度、柔轮柔性
- 传感：高分辨率 / 双编码器、关节力矩传感、IMU 与末端加速度计
- 结构：连杆刚度与阻尼设计、质量分布、减重
- 驱动电子：电流环带宽、采样率、抗混叠

### 理论视角（衔接 ④）
- 扰动分类：L2 能量型 vs L∞ 有界型 ★（论文分别给出 H∞ 增益与均方界）
- 性能上限：抑振不是无限低，证书给出可达界 ★（定理 3）

## ④ 数学理论保证（论文核心贡献区）

### 建模层保证
- 全局无奇异位姿参数化：单位 DQ 双覆盖 SE(3)，避免欧拉角万向锁与参数奇异 ★
- 微分结构内化：HDQ / TODQ 幂零单位承载导数，正运动学一次 O(n) 连乘输出（位姿，twist，任务空间加速度，J̇q̇）★（Leibniz 法则内化于乘法）

### 误差体系保证 ★（定理 1、2）
- 几何一致误差：一次乘法同时生成右不变位姿误差 + 几何一致 twist 误差（消除位姿 / 速度误差分离）
- 严格级联误差运动学：ė_z = A(x̃)·e_ξ（闭环结构可积）
- 兼容性：0 阶截断退化为既有 DQ 控制结果（[P2]）

### 控制层保证 ★（定理 3）
- 精确耗散等式：V̇ = −e_ξᵀK_d·e_ξ + e_ξᵀd（无任何放缩）
- 无扰动情形：水平集不变性 + 渐近收敛（稳定性）
- L2 扰动：H∞ 增益的 Schur 补充要判据（旋转 / 平移分量拆分）（扰动衰减）
- L∞ 扰动：twist 误差均方极限界（含乘性不确定性）（有界性 / ISS）

### 行业通用理论工具箱
- Lyapunov / LaSalle / Barbalat 引理
- ISS、级联系统与小增益定理
- 无源性 / 耗散性（passivity-based control）
- H∞ / LMI、奇异摄动（柔性系统）、离散时间稳定性

### 尚未保证 / 行业开放问题
- 离散采样、控制延迟、量化下的证书
- 全局 vs 局部：大误差收敛域的精确刻画
- 摩擦 / 间隙等非光滑不确定性的严格保证
- 输出反馈（无全状态测量）下的同等级保证
- 柔性体（无穷维 / 模态截断）下的保证
