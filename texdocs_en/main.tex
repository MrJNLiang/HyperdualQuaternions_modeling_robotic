% ================================ Abstract ================================
\begin{abstract}
\noindent
Unit dual quaternions provide a globally singularity-free parametrization of rigid-body pose, but their error formulations cover only the pose and velocity levels and therefore do not interface with acceleration-level dynamics. This paper introduces the third-order dual quaternion (TODQ), with which a single product of kinematic elements yields the pose, the twist, and the task-space acceleration of a serial chain. On two hyper-dual quaternion (HDQ) elements we then build an error system that generates a right-invariant pose error and a geometrically consistent twist error in one multiplication, and we show that the resulting error dynamics is a strict cascade. The proposed geometrically consistent computed-torque law endows the closed-loop storage function with an exact dissipation identity, from which nominal convergence, a necessary-and-sufficient condition for $L_2$ disturbance attenuation, and a mean-square bound for bias-type disturbances follow simultaneously. The $L_2$ gain can be optimized in closed form: the certified value equals the reciprocal of the smallest damping and coincides with the true $H_\infty$ norm of the linearized loop, so a desired attenuation level converts into a damping lower bound by one division. Thirty-three runs on a six-degree-of-freedom robot arm show that four control laws match each other in tracking accuracy under an equal gain budget, while only the proposed law's attenuation certificate holds throughout, with the certified gain tightened from $1/6\,\mathrm{s}$ to $1/15\,\mathrm{s}$.
\end{abstract}

\medskip
\noindent\textbf{Keywords}: dual quaternion; hyper-dual quaternion; third-order dual quaternion; polynomial algebra; geometrically consistent error; $H_\infty$ control; disturbance attenuation; robot manipulators
