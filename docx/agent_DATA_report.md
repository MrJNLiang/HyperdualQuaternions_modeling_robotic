### 1.4 gamma_sweep（H∞ 证书，定理 3(c)）——论文 §6 完全未用

数据源：`TNDQ_sim/results/gamma_sweep.csv`（21 行 = 表头 + 20 数据行：A 组 8、B 组 7、
C 组 6）。语义已从 `run_gamma_sweep.py` 逐行确认：

- **A 组（证书扫描）**：固定 tuned 增益（K_d=24I，p_O=320，p_T=80），只扫分析参数
  γ_a∈[1.0, 0.14] 判定 (5.6a) 可行性。`cert_ok` 在 **γ_a=0.14 翻转**（level=26.01>24），

  O_rms_ss、exi_rms、measured_l2 全部不变）——直接实验证据："γ_a 是分析参数，不进
  控制律 (5.2)，只改变证书可判定性"。
- **B 组（综合模式）**：κ=γ_a²、K_d=γ_a⁻²I 取 (5.6a) 等号，`certified_l2`=γ_a²=1/λ_min；
  `measured_l2`≤`certified_l2` 仅对 γ_a≥0.354 成立；γ_a≤0.25 时测得 L2 增益超过认证值
  （脚本明示原因：measured_l2=√(E_ξ/E_d) 未扣 V(0)，小 γ_a 时由初始瞬态主导）。
- **C 组（旧理论 C3）**：γ 是综合参数（kO=kT=√2/γ 直接进控制律），无认证列
  （cert_ok=0、certified_l2=nan）——"可调但不可证"。
- **完整不等式 (5.6)**：`hinf_lhs(=E_ξ/κ) ≤ hinf_rhs(=γ_a²E_d+2V(0))` **21/21 行全部
  成立**——含 2V(0) 初始能量项后，定理 3(c) 的能量不等式在所有运行中严格满足。
