## 1. 场景文件识别与运行时核查清单

### 1.1 关于 .ttt 格式的事实说明

`.ttt` 是 CoppeliaSim 专有二进制序列化格式（含压缩），**不可静态文本解析**
（已验证：对文件全文做 `LBR4|joint|Cup|chair` 正则提取为 0 匹配）。场景内容
以用户描述 + 仓库先验为准，并在首次连接时用 ZMQ Remote API 枚举核实，
枚举结果存档为 `docx/scene_inventory.txt`，作为后续所有实验的对象路径唯一依据：

```python
# 场景自检脚本（连接后执行一次）
from coppeliasim_zmqremoteapi_client import RemoteAPIClient
sim = RemoteAPIClient().require('sim')
for h in sim.getObjectsInTree(sim.handle_scene):
    alias = sim.getObjectAlias(h, 2)          # 完整路径
    otype = sim.getObjectType(h)
    if otype == sim.sceneobject_shape:
        mass = sim.getShapeMass(h)
        dyn  = not sim.getObjectInt32Param(h, sim.shapeintparam_static)
        print(f'{alias:45s} shape  mass={mass:.3f}  dynamic={dyn}')
    elif otype == sim.sceneobject_joint:
        print(f'{alias:45s} joint  mode={sim.getJointMode(h)}')
```

## 2. 场景对象在实验中的角色分配

| 对象 | S1 定点控制 | S2 圆周跟踪 | 扰动实验 |
|---|---|---|---|
| LBR4+ | 被控对象（力矩模式） | 同左 | 同左 |
| **杯子** | **定点目标**：目标位姿 = 杯口上方 $h=0.10$ m 的预抓取位姿（z 轴竖直向下） | 圆心参照：圆平面在杯口上方 0.15 m | **突加负载源**：$t=t_p$ 时刻将杯子附着到 tip（`sim.setObjectParent` + 力学附着），等效末端质量突变 |
| **椅子** | 大初始误差用例的姿态参照：目标在椅背另一侧，迫使大姿态重定向 | 障碍：圆轨迹 60° 弧段距椅背最近 5 cm，跟踪误差直接决定是否碰撞 | **接触扰动源**：变体轨迹与椅背擦碰，接触力经引擎作用为非建模外力矩 |

角色分配的意图：把"椅子、杯子"从装饰物变成**有物理意义的目标与扰动通道**，
使场景实验能同时覆盖总方案 E1–E6 中的定点（E4）、跟踪（E1/E5）、bias 扰动（E3）
与接触扰动（新增 E7）四类工况。

## 3. 对比控制器组（场景裁剪版）

从总方案 §5.2 的五控制器裁剪为四个（关节空间 CTC 在任务空间场景中意义有限，
降为可选）；全部走**同一力矩接口** `sim.setJointTargetForce`，同一名义模型
$\hat M,\hat C,\hat g$（[11] 参数表 + §1.2 第 5 项核对）、同一阻尼伪逆、
同一增益折算规则（闭环带宽 $\omega_n=4$ rad/s，$\zeta=1$）：

| 编号 | 控制器 | 律（总方案编号） | 误差参数化 | $\dot J\dot q$ 来源 |
|---|---|---|---|---|
| C2 | 操作空间 CTC | L2，式 (3.5) | 旋转矩阵误差 + 平移 | 数值差分 |
| C3 | DQ 鲁棒 CTC | L7，[9] | DQ 对数映射 | 差分/手工递推 |
| C5 | **TNDQ 几何一致 CTC** | L8，式 (4.1)/(5.2) | $(e_z,e_\xi)$，定理 1/2 | $\mathcal A_2$ 链免构造 |
| C4* | Slotine–Li 自适应（仅杯子负载场景） | L4，式 (3.9) | 关节空间 $s$ | 不需要 |

**明确排除**：运动学 H∞ 律（[P2] 式(12)）+ 内置速度环**不作为对比基准**，
理由见总方案 §2.2（被控对象不同、误差通道未激励、γ 量纲不可比）。
仅在附录性单次运行中展示其在力矩模式场景下的退化现象，作为
"为什么不能比"的示例证据，不进入统计。

## 4. S1：定点控制实验设计

### 4.1 任务定义

调节问题：从初始位形驱动末端到杯口上方预抓取位姿并保持。

- 目标位姿：$p^* = p_{\mathrm{cup}} + [0,0,0.10]^T$（基座系换算后），
  姿态 $r^*$ = 末端 z 轴竖直向下、x 轴对齐基座 x（固定单位四元数）；
  合成 $\boldsymbol x_d = r^* + \tfrac12\varepsilon\, p^* r^*$，
  且 $\boldsymbol\xi_d=\dot{\boldsymbol\xi}_d=0$（定点 ⇒ 式 (5.2) 前馈项
  自动退化为纯反馈，控制律无需改动，`simdata/trajectory_generator.py`
  增加常值轨迹模式即可）。
- 初始位形三档（姿态误差从小到大）：
  - **S1-a 小误差**：`Q_INIT`（`config/params.py`），姿态误差约 10–20°——常规工况；
  - **S1-b 中误差**：末端初始朝上，姿态误差约 90°；
  - **S1-c 大误差**：初始姿态误差 ≥ 150°（接近对径点），且目标位于椅背另一侧
    ——同时检验 unwinding 处置（定理 1(i) 符号翻转）与参数化退化
    （总方案 §4.2(i)：C2 的旋转矩阵误差 $\tfrac12(R_d^TR-R^TR_d)^\vee$ 在
    大误差下增益趋零，C3/C5 无此问题）。

### 4.2 场景变量

| 变体 | 扰动 | 目的 |
|---|---|---|
| S1-N | 无 | 标称收敛速率与稳态精度基线（对照总方案 §1.3(a)：加速度级理想仿真 10 s 收敛至 5.4e-4） |
| S1-D1 | L2 力矩脉冲（§6.1） | 定点保持阶段的扰动衰减，实测 L2 增益 vs 认证 0.125 |
| S1-D2 | 杯子突加负载（§6.2） | ISS 极限球核验：负载后稳态误差 ≤ 式 (5.7) 界 |
| S1-D3 | 编码器噪声（§6.4） | 三控制器微分量获取方式的噪声敏感度 |

### 4.3 专用指标（通用指标见 §7）

- 2%/0.5% 安定时间；姿态测地距离 $\theta_e$ 的收敛曲线是否单调
  （C5 的 $V$ 在理想仿真中严格单调，总方案 §1.3(a)，此处检验引擎闭环下是否保持）；
- S1-c 专用：累计旋转角（判定 unwinding，绕远路 > $2\pi-\theta_0$ 即判失败）、
  收敛成功率（10 种随机初始扰动 × 3 控制器）；
- 保持段（收敛后 5 s）位置抖动 RMS——力矩模式下静摩擦/引擎接触求解器
  引起的极限环幅值，衡量各律对低速摩擦区的鲁棒性。

## 5. S2：圆周运动跟踪实验设计

### 5.1 任务定义

跟踪问题：末端沿水平圆周匀速运动，姿态保持竖直向下。

- 圆心 $c = p_{\mathrm{cup}} + [0,0,0.15]^T$，半径 $R=0.12$ m，圆平面水平；
- 期望轨迹直接用 `simdata/trajectory_generator.py` 的圆模式
  （TNDQ 表示，解析给出 $\boldsymbol x_d,\boldsymbol\xi_d,\dot{\boldsymbol\xi}_d$；
  三个控制器共享同一 $\boldsymbol x_d$ 采样，C2/C3 各自换算成自己的
  误差参数化，保证目标一致）；
- 速率三档：$\omega\in\{0.25,\ 1.0,\ 2.5\}$ rad/s
  （末端线速度 0.03 / 0.12 / 0.30 m/s；最高档使 $\|\dot q\|\approx1.5$ rad/s，
  进入 $\dot J\dot q$ 与 $C\dot q$ 不可忽略的中高速域——总方案 §2.2(ii)、
  扩展篇 §3.4 预言差异在此档兑现，向心加速度 $\omega^2R\approx0.75$ m/s²）；
- 起始：末端先经 S1 流程到达圆周起点，再切入跟踪（避免初始瞬态污染跟踪统计）；
- 椅子障碍弧段：圆周其中 60° 弧段与椅背最近距离设计为 5 cm，
  跟踪误差 > 5 cm 即碰撞——把"误差指标"翻译成有物理后果的通过/失败判据。

### 5.2 场景变量

| 变体 | 扰动 | 目的 |
|---|---|---|
| S2-N($\omega$) | 无，三档速率 | 前馈质量：稳态跟踪误差 vs $\omega$ 的增长曲线（C5 预期近乎平坦——引理 1 前馈精确消化向心项，理想仿真证据见总方案 §1.3(d)；C2 预期随 $\omega^2$ 增长） |
| S2-D1 | 高速档 + L2 脉冲 | 动态跟踪下的 H∞ 核验（对照总方案 §1.3(b) 模式：扰动后误差回落至准扰动前水平） |
| S2-D2 | 中速档 + 杯子突加负载（1/4 周期处） | 负载突变下的跟踪恢复时间与新稳态球 |
| S2-D3 | 中速档 + 椅背擦碰弧段（§6.3） | 非建模接触扰动下三控制器的恢复行为（接触是名义模型完全不含的通道，最能检验证书对"任意 $L_2/L_\infty$ 扰动"的承诺） |

## 6. 扰动注入方案

### 6.1 L2 有限能量力矩脉冲（对应定理 3(c)）

复用 `simdata/input_simulation.py` 的 L2 波形（有限支撑、能量已知），
经 $\hat M$ 折算为关节力矩后叠加到控制输出：
$\tau_{\mathrm{cmd}}=\tau_{\mathrm{ctrl}}+\hat M\,w_{L2}(t)$，
支撑 $[t_p,\,t_p+1\,\mathrm s]$，$\int\|w_{L2}\|^2dt$ 记录为分母能量。
在线能量核算直接复用 `control/performance.py::PerformanceAccumulator`
（实测增益 $\sqrt{E_{e_\xi}/E_d}$ vs 认证 $1/\lambda_{\min}(K_d)=0.125$）。

### 6.2 杯子突加负载（L∞ 偏差型，对应定理 3(d)）

$t=t_p$ 时把杯子（质量 $m_c$，§1.2 第 6 项实测）附着到 tip：
等效为 $\Delta M,\Delta g$ 的阶跃偏差，折算加速度级偏差
$\|d_b\|_\infty\approx\|\hat M^{-1}(\Delta M\ddot q+\Delta g)\|_\infty$
（附着前后模型差离线估算）。ISS 判据：
新稳态 $\|e_\xi\|\le\|d_b\|_\infty/\lambda_{\min}(K_d)$（式 5.7）。
C4*（Slotine–Li）在此场景加入：预期渐近误差最小（参数自适应吸收 $m_c$）
但恢复过程慢于 C5，且无 L2 证书——展示"自适应 vs 鲁棒"的经典权衡。

### 6.3 椅背接触扰动（非建模接触脉冲）

变体轨迹使末端以 ≤ 2 cm 过盈擦过椅背边缘（引擎解算接触力，
时长约 0.1–0.3 s 的力脉冲）：
- 记录 `sim.getContactInfo` 的接触力积分作为扰动能量估计；
- 判据：接触结束后误差回到扰动前水平的恢复时间、期间无失稳/振荡发散；
- 安全上限：关节力矩饱和 $|\tau_i|\le\tau_{\max,i}$（LWR4+ 额定值），
  任何控制器触发饱和即记录（饱和处理统一为限幅，不做各律特殊处理）。

### 6.4 测量噪声

$q$ 叠加 16 bit 编码器量化 + 高斯噪声（$\sigma_q=5\times10^{-5}$ rad），
$\dot q$ 由带低通的差分给出（模拟无测速机情形）。
预期差异机制（总方案 §6.2 第三条）：C2 的 $\dot J$ 差分把噪声二次放大，
C5 的 $\dot J\dot q$ 是代数通道读数，噪声只经 $\dot q$ 一次线性进入。

## 7. 指标、判据与预期差异

### 7.1 指标（与总方案 §5.4 对齐，场景新增两项）

- **A 收敛性**：$t_s$（2%）、稳态误差、RMS、ITAE、超调；S1-c 收敛成功率；
  **[场景新增] 椅子弧段最小间隙**（碰撞判据）；
- **B 计算/实时**：单步壁钟（分段：链传播 / 动力学装配 / 控制律）、99 分位、
  超时率（>2 ms）；
- **C 鲁棒性**：实测 L2 增益 vs 各自理论界、负载/接触后恢复时间、
  噪声方差放大系数；
- **D 数值稳定性**：C2 的 $\|R^TR-I\|_F$、C3 的 DQ 范数漂移、
  C5 的 $c_0,c_1,c_2$（判据 < 1e-12；理想仿真参照 ≤ 2e-15）；
  **[场景新增] 保持段极限环幅值**（S1 专用）。

每变体 × 每控制器 10 个随机种子，配对 Wilcoxon（α=0.05），
判优规则沿用总方案 §5.4 预注册条款。

### 7.2 预期差异一览（可证伪预测）

| 工况 | C2（矩阵操作空间 CTC） | C3（DQ 鲁棒 CTC） | C5（TNDQ，式 5.2） |
|---|---|---|---|
| S1-a/b | 三者同量级 | 同左 | 不劣于（"无退化"检查） |
| S1-c 大误差 | 增益退化、可能收敛失败或绕远路 | 正常收敛（unwinding 处置后） | 正常收敛，且 $\dot e_z=Ae_\xi$ 精确 ⇒ 轨迹贴指数包络 |
| S2-N 速率扫描 | 稳态误差 $\propto\omega^2$ 增长（$\dot J$ 差分 + 参数化损失） | 介于两者 | 近平坦（前馈+免构造 $\dot J\dot q$），高速档领先 3–10 倍 |
| S2-D1 / S1-D1 | 实测增益无先验界 | 同左 | 实测 ≤ 0.125（复现 0.121≤0.125 模式） |
| 负载 D2 | UUB，无显式半径 | 同左 | 稳态落入 (5.7) 球；C4* 渐近最优但恢复慢 |
| 接触 D3 | 恢复行为无证书 | 同左 | 恢复时间可由 ISS 论证定性预测 |
| 噪声 | 误差方差放大最明显 | 中等 | 最小 |
| 计算 B | 两次 $J$ + 差分 | 递推/差分 | 一条链全量输出，单步 ≲2 ms（1.63 ms 实测外推 + $M,C,g$ 装配 ≈1 ms 估算） |
| 数值 D | 需周期再正交化 | 范数投影 | 残差 = 内建健康度指示，免费监控 |

若 S2-N 高速档与 S1-c 两项优势未显现，按总方案 §7 的证伪出口处理
（说明优势不能从加速度级理想仿真外推到引擎闭环）。
