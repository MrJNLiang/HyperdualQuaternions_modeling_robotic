## 目标

把 `q`/`home` 从“低刚度重力保持 + 位置弹簧”改成真正的主动回零，同时不改模式、不碰 joint7、不放宽任何总力矩边界。

## 具体修改

### 1. 增加专用 Home MIT 增益（`tndq_mit_controller.py`）

- `MITSafetyProfile` 新增：
  - `home_kp = [120, 120, 120, 18, 18, 18]`
  - `home_kd = [8, 8, 8, 2, 2, 2]`
  - 数值直接取自官方 `rebotarm_dm.yaml` 的 MIT 参数，不新建自定义值。
- `HOLD/TRACKING` 继续使用现有 `kp=2/kd=1`，不受影响。
- `_validate_safety()` 同步校验新数组形状与正值。

### 2. 把 Home 速度参考真正发给固件

- 控制器新增每帧命令状态：
  - `_vel_cmd`
  - `_kp_cmd`
  - `_kd_cmd`
- `_bus_loop()` 读取并发送这三个字段，不再固定 `vel=0` 和 `safety.kp/kd`。
- HOMING 分支计算：
  - `q_ref = q_start + s * (q_home - q_start)`
  - `qd_ref = ds * (q_home - q_start) / T`
  - `qd_ref` 逐轴裁剪到 ±0.30 rad/s。
- 参考位置增加安全滞后限幅：
  - `q_ref` 每轴限制在实测 `q ± 0.20 rad` 内；
  - 防止关节卡住时固件位置弹簧力超过 URDF effort limit。
- 完成条件保持：
  - `u >= 1`
  - `max|q| < 0.02 rad`
  - `max|qd| < 0.05 rad/s`

### 3. 修正总努力矩边界（`_bound_feedforward`）

- 函数签名扩展为接收当前帧的：
  - `vel_cmd`
  - `kp_cmd`
  - `kd_cmd`
- 固件 PD 项改为：
  - `kp*(pos_cmd - q) + kd*(vel_cmd - qd)`
- 仍保证估计总 MIT 努力矩不超过 URDF effort limit。
- `start()` 与 `_bus_loop()` 的调用点同步更新。

### 4. 修复 FAULT_HOLD 拉回旧目标的 bug

- `_enter_fault()` 当前把 `_pos_cmd` 恢复成旧的 `_q_hold`，会导致超时后机械臂被拉回进入 HOLD 时的旧位置。
- 改为故障瞬间锁定当前反馈位置：
  - `_q_hold = 当前 snapshot.q`
  - `_pos_cmd = 当前 snapshot.q`
- `stop()` docstring 中的 `0.10 rad/s` 更正为实际的 `0.30 rad/s`。

### 5. 不做的事

- 不切换 POS_VEL / VEL。
- 不调用 `RebotArmEndPose.safe_home()`（它会读全局状态并触碰 gripper/joint7）。
- 不修改 `rebotarm_dm.yaml`。
- 不放宽任何力矩、速度或完成阈值。
